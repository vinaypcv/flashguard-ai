# FlashGuard Flutter app

See the [repository README](../README.md) for the project overview and
storage safety limits. Run `flutter pub get`, `flutter analyze --fatal-infos`,
`flutter test`, and `flutter run` from this directory.

The dashboard's default source path points to a virtual drive on the same
computer. Native mobile storage access and drive discovery are not implemented.
